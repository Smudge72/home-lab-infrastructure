# Enterprise Infrastructure & Security Homelab

## Overview

This repository documents the design, deployment, administration and troubleshooting of a multi-platform infrastructure and security homelab.

## Current Environment

### Core Infrastructure

- OPNsense Firewall
- Cisco CBS350 Managed Switch
- Proxmox VE
- Windows Server 2019
- Active Directory Domain Services
- DNS
- Ubuntu Server 24.04

### Domain

- Domain: lab.local
- Domain Controller: DC01
- DNS Server: 192.168.10.114

### Networking

- VLAN 10 – Management
- VLAN 20 – Users
- VLAN 30 – Servers
- VLAN 40 – Lab

### Tools

- PowerShell 7
- Wireshark
- Nmap
- Packet Tracer
- Visual Studio Code
- Git & GitHub
